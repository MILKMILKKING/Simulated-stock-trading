# 📈 模拟股票交易系统

一个基于 K 线图的股票交易模拟训练平台，帮助用户提升技术分析能力和交易决策水平。

## ✨ 功能特点

- 🎲 **随机股票场景** - 系统随机选择 A 股股票和历史时间段，确保每次训练都是全新体验
- 📊 **专业 K 线图** - 基于 ECharts 的专业 K 线图表，支持缩放、拖拽等交互操作
- 💰 **真实交易体验** - 100 万初始资金，完整的买入/卖出操作流程
- 📱 **现代化 UI** - 基于 Tailwind CSS 的深色主题界面，清晰直观
- 📈 **实时统计** - 实时显示账户信息、持仓情况、盈亏统计
- 🔍 **交易复盘** - 详细的交易记录和资产变化分析，帮助总结经验
- 💾 **本地存储** - 使用 localStorage 自动保存交易数据
- 🎯 **逐日推进** - 点击查看下一天 K 线，模拟真实交易节奏

## 🚀 本地开发

### 前置要求

- Node.js 18+
- npm 或 yarn

### 安装步骤

```bash

git clone https://github.com/MILKMILKKING/Simulated-stock-trading.git
cd Simulated-stock-trading

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 📖 使用指南

### 1. 开始游戏
- 打开应用后，系统会自动随机选择一只股票和时间段
- 初始显示前 5 天的 K 线数据
- 初始资金：100 万元人民币

### 2. 查看 K 线
- 使用鼠标滚轮或拖拽可以缩放和移动图表
- 悬停在 K 线上可查看详细数据（开盘价、收盘价、最高价、最低价、成交量）
- 图表下方显示成交量柱状图

### 3. 交易操作

#### 买入
- 输入买入数量或使用快捷按钮（1/4、1/2、3/4、全部）
- 点击"买入"按钮执行交易
- 系统会根据当前价格和可用资金判断是否可以买入

#### 卖出
- 输入卖出数量或使用快捷按钮
- 点击"卖出"按钮执行交易
- 只能卖出已持有的股票数量

### 4. 推进时间
- 点击"下一天 →"按钮查看下一个交易日的 K 线
- 每次推进都会记录当天的资产状态
- 到达时间终点后自动显示复盘界面

### 5. 查看复盘
- 点击"查看复盘"按钮打开详细的交易分析
- 包含：交易总览、交易统计、交易记录、资产变化等
- 帮助分析交易策略的优劣

### 6. 重新开始
- 点击"重新开始"按钮开始新一轮训练
- 系统会重新随机选择股票和时间段

## 📊 功能模块

### 账户信息面板
- 当前股票名称和代码
- 当前价格
- 可用资金
- 持仓数量和市值
- 总资产
- 盈亏金额和收益率

### K 线图表
- 标准蜡烛图显示
- 涨跌颜色区分（红跌绿涨）
- 成交量柱状图
- 买入/卖出标记点
- 可交互的时间轴

### 交易面板
- 买入操作区
- 卖出操作区
- 快捷数量选择
- 下一天按钮
- 实时消息提示

### 复盘模态框
- 交易总览（初始/最终资金、盈亏）
- 交易统计（次数、平均价格）
- 完整交易记录表格
- 资产变化曲线

## 🎯 训练建议

1. **观察趋势** - 注意 K 线形态和价格走势
2. **控制仓位** - 不要一次性买入全部资金
3. **止盈止损** - 设定合理的盈利和止损目标
4. **复盘总结** - 每次结束后认真查看复盘数据
5. **多次练习** - 重复训练以提升技术分析能力

## 📝 数据说明

目前使用模拟数据生成 K 线，特点：
- 符合真实股票价格波动规律
- 自动排除周末
- 价格、成交量在合理范围内

未来可接入真实的股票 API（如 Yahoo Finance）获取历史数据。

## 🔒 隐私说明

- 所有数据仅存储在浏览器本地（localStorage）
- 不收集任何用户信息
- 不与服务器通信
- 清除浏览器缓存会删除所有交易记录
